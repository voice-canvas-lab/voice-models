# Жанна: предварительная ASR-оценка ru-text-only-1.0.1

Завершён TTS → аудиоаудит → искусственный шум → Whisper/GigaAM → оценка. Ни одна модель не получает эталон, args, context или action_id как подсказку. При подготовке публикации выполнены только проверки кода, файлов и повторный расчёт метрик по готовым гипотезам.

## Источник и состав

Источник: [PR №5](https://github.com/voice-canvas-lab/voice-models/pull/5), файл `data/v1/dataset/samples.jsonl`, commit `a1dff1335109d12e5594391066d6a260ce54601b`. Точный снимок: [samples.jsonl](../../examples/zhanna-v1/samples.jsonl), [source.json](../../examples/zhanna-v1/source.json). SHA256: `48300af1561a011f48adaa135028c80bbd847d534756790a00fed12f1baac535`.

В оригинале 163 команды. Производная версия сохраняет все строки и поля, заменяя только text; изменены 118 текстов. В основной прогон заранее выбраны **151 команда, 47 групп**: train 99, validation 26, test 26. Полные sample_id: [sample_ids.json](../../examples/zhanna-v1/experiment-text-only-v1.0.1/sample_ids.json), вход: [ready_samples.jsonl](../../examples/zhanna-v1/experiment-text-only-v1.0.1/ready_samples.jsonl). Несоответствия text с args/context/action_id не исправлялись и не служили основанием исключения.

12 неразрешённых вопросов произношения сохранены отдельно, исходные значения не исправлены:

| Латинские `note`, `file`, `document` без согласованного чтения | sample_000040, sample_000148, sample_000150, sample_000151, sample_000152, sample_000153 |

[Точная таблица текстов и вопросов](../../examples/zhanna-v1/experiment-text-only-v1.0.1/PRONUNCIATION_REVIEW_12.md). Исключения относятся только к произношению, не к качеству разметки действий.

## Произносимый эталон

Версия правил — **ru-text-only-1.0.1**: [код](../../scripts/spoken_text_text_only.py), [описание и хеши](../../examples/zhanna-v1/text-only-v1.0.1/rules.json), [original_text → spoken_text, причины и флаги](../../examples/zhanna-v1/text-only-v1.0.1/mapping.jsonl).

Правила используют только исходный text, без LLM, подстановки разметки и исправления опечаток/названий/года. Числа записаны словами с сохранением значений и ведущих нулей; непрозрачные цифровые ID читаются по цифрам, без догадки о префиксе. Внутренние дефисы и подчёркивания становятся границами слов/паузами; названия знаков не добавляются. Обычная пунктуация сохранена для интонации. Явная версия `2.0` после слова «версия» читается «два точка ноль». Дата/время в имени читаются как исходные числовые компоненты без календарного переосмысления. Алфавит и регистр не проговариваются. Это **не посимвольно обратимое кодирование имени**. Производный text одновременно служит входом TTS и эталоном ASR; по гипотезам его не меняли.

Шум — искусственный белый гауссовский; мощность измерялась по всему PCM, включая паузы. Аудит проверил формат, непустой сигнал, клиппинг, покрытие, связи ID, длительности, фактический SNR и побитное воспроизведение шумовых файлов. Клиппинга 0; максимальная ошибка SNR 0,000163 дБ. Максимальная длительность **18,425 с**, превышений ограничения GigaAM 25 с нет. Общий шлюз проверен до обеих полных ASR; обрезаний/исключений не было.

Обе модели обработали **1359/1359**, пустых и отсутствующих гипотез 0. SHA256 всех WAV совпали у обеих ASR, с контрольным состоянием до ASR и фактическими файлами. Две попытки GigaAM завершились HTTP 429 при запросе метаданных **до распознавания**. Продолжение использовало локальный snapshot той же ревизии, проверенный по LFS SHA256/Git blob ID; параметры адаптера не менялись. Whisper и TTS не запускались повторно. Логи неудач сохранены локально; доказательства восстановления — provenance.json.

## Метрики

| Набор | Модель | WAV | WER | CER | Числовой WER | Числовой CER | RTF |
|---|---|---:|---:|---:|---:|---:|---:|
| Pilot | whisper | 5 | 64.81% | 49.17% | 58.18% | 43.31% | 0.5568 |
| Pilot | gigaam | 5 | 64.81% | 52.21% | 58.18% | 46.19% | 0.0956 |
| Main | whisper | 1359 | 44.09% | 31.57% | 43.78% | 31.33% | 0.6059 |
| Main | gigaam | 1359 | 35.90% | 27.81% | 35.64% | 27.62% | 0.2092 |

Обычная нормализация: NFC → lowercase → ё/е → Unicode-пунктуация в пробелы → схлопывание пробелов. Числа, слова и отрицания сохранены; CER включает пробелы. Корпусный WER/CER — сумма ошибок / сумма эталонных слов/символов; средние по строкам не используются. Обычные знаменатели: 18522 слова и 127827 символов.

Числовая канонизация **ru-numeric-eval-1.0.0** независимо применяется к эталону и гипотезе, без восстановления по эталону. Она поддерживает ограниченные явные даты/время/версии/известные ID, сохраняет порядок и ведущие нули, неизвестное оставляет с флагами. Например, `17:4029` не исправляется догадкой. Знаменатели дополнительной оценки — 18540 и 128169; она не заменяет обычную оценку. Числовые флаги имеют 918 эталонов, 886 гипотез Whisper и 854 GigaAM. Написание чисел цифрами вместо слов объясняет часть высокого WER, но этим нельзя объявить все расхождения эквивалентными.

Основной набор содержит ошибки слов/символов у 1085 WAV Whisper и 955 GigaAM. Это не технические отказы. 310 WAV отмечены прежними эвристиками как кандидаты для прослушивания; это не доказанные пропуски TTS и не основание исключения.

## Примеры и ручная проверка

- Обычная команда sample_000027 / xenia/clean: эталон «Открой документ Инструкция по ремонту»; Whisper «Открой документ инструкции по ремонту.» — 1 ошибка из 5 слов; GigaAM «Открой документ.Инструкция по ремонту.» — 0 после обычной нормализации.
- sample_000157 / xenia/clean: «два точка ноль» → `2.0` у Whisper даёт 3/9 обычных ошибок, но 0 по числовой оценке. У GigaAM дополнительно «изменения» → «изменение»; эта ошибка не исчезает после числового преобразования.
- sample_000102 / xenia/SNR10, `audio_0097_xenia_snr10`: в гипотезе Whisper есть длинная цепочка `26`; по текстовому эталону — 119 ошибок на 44 слова. Пользователь слышит повторы цифр и в аудио. Их точное количество и соответствие эталону не установлены; вклад синтетического аудио и ASR не разделён, поэтому все повторы нельзя приписывать только Whisper.
- sample_000119 / baya/SNR20, `audio_0112_baya_snr20`: пользователь не слышит повторов цифр в аудио, хотя в гипотезе Whisper есть длинный повторяющийся хвост, включая `9`. По этому наблюдению хвост добавлен Whisper в данной записи; вывод не переносится на другие WAV. По текстовому эталону — 109 ошибок на 6 слов. Индивидуальный WER может превышать 100% из-за вставок; запись включена в корпус полностью.

[Все шесть записей, полные эталоны/гипотезы и точные Invoke-Item](zhanna-text-only-v1.0.1/review-six.md), [JSON с audio_id и SHA256](zhanna-text-only-v1.0.1/artifacts/review-six.json). Две записи с повторами в гипотезе Whisper сами являются шумовыми; дополнительно выбраны SNR20/SNR10 версии двух обычных команд.

Наблюдения пользователя от 12 ноября 2026 года относятся только к записям №3 и №4 и сохранены отдельно с точными audio_id/SHA256: [manual-review-observations.json](zhanna-text-only-v1.0.1/artifacts/manual-review-observations.json). Остальные четыре записи review-six не отмечены проверенными. Наблюдения не являются подтверждением полного соответствия произношения эталону. Эталоны, гипотезы, freeze и метрики оставлены без изменений.

## Ограничения и воспроизведение

Это **предварительная оценка выбранных 151 из 163 команд на синтетическом аудио**. Ручное подтверждение относится только к пяти WAV xenia пилота: [audio_id/SHA256 и подтверждение](zhanna-text-only-v1.0.1/artifacts/manual-review-five.json). Оно не подтверждает весь набор и записи других голосов. Аудиоаудит не доказывает полноту/правильность произношения TTS; синтетическое аудио может отличаться от текста, в том числе содержать повторы цифр, как услышано пользователем в одной из двух дополнительно прослушанных записей. Поэтому эти метрики оценивают весь тракт относительно текстового эталона и не изолируют ошибки ASR от несоответствий TTS. В исходных текстах также есть известные проблемы. 1359 WAV — девять коррелированных версий 151 команды, а шум не моделирует всё реальное окружение. Общий WER нельзя напрямую сравнивать со старым прогоном 163 команд как доказательство улучшения.

**Скорость предварительная:** RTF = сумма времени распознавания / 8689,95 с аудио. Суммы времени — 5265,2274 с Whisper и 1817,6013 с GigaAM; загрузка, прогрев и запись результатов исключены. Аудиодекодирование включено; измерения получены в отдельных запусках разных рантаймов и точностей на одном CPU. Все времена сохранены, включая медленный хвост Whisper: 33,8726 с для sample_000102 xenia/SNR10 и RTF 7,1607 для sample_000139 baya/SNR20. Консервативный порог `>60 с или >10 медиан` всего запуска не сработал; это не доказывает стабильность скорости. Повторы декодирования не устранялись настройкой модели, выбросы/ошибки не удалялись. [Медленные записи](zhanna-text-only-v1.0.1/artifacts/slow_records_retained.json).
